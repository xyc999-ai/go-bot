# Go Bot Web 视觉与交互重构

软件应用：自托管 Personal Agent 的真实 Web 客户端，主要操作为进入会话并发送消息。

状态：已完成实现与本地浏览器验收。分支：`feat/frontend-refresh`。

## 1. 设计依据与取舍

主参考：[Lumeo - AI Assistant Result](https://dribbble.com/shots/25712260-Lumeo-AI-Assistant-Result)，Barly Design / Uxerflow。已在真实浏览器观看 15.68 秒原型视频，逐帧检查欢迎页、用户消息、结果展开、导航和输入区。

辅助参考：[Taste Skill](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md) 的字体层级、间距、图标、边框对比、焦点、悬浮反馈和真实页面视觉复查。用户指定的原型优先，不采用该 skill 面向营销页的随机配色、整屏 hero、营销卡片、shader 或营销页自动检查脚本。

还原原型中的近白画布、细窄导航、轻边框、低阴影、紧凑工具条、淡紫选中态、深色发送按钮和克制的分层进入动画。使用 Go Bot 自有 logo 和真实功能，不复制原型的商标、文案、图片和代码。原型右侧 Sources / Suggested tasks / Suggested questions 不引入，也不制造当前后端没有的能力。

## 2. 功能与页面映射

| 区域 | 真实功能 | 新表现 |
| --- | --- | --- |
| 固定窄导航 | 会话、任务、插件市场、文件系统、设置、账号与停止 Host | 64px 左轨；20px Lucide 细线图标；当前项浅紫底与侧边指示；悬浮/键盘提示名称 |
| 会话侧栏 | 主会话、最近会话、新建、归档、分页、待审批/问题标记 | 左轨右侧展开约 264px；会话区随之平移/收窄；主会话单独强调；行尾保留菜单 |
| 会话顶部 | 当前会话、模型/端点、执行权限 | 紧凑上下文工具条；模型、权限可选；右侧主题和语言入口 |
| 会话正文 | 用户/助手、有序内容块、流式播放、工具卡、问题/审批 | 用户淡紫气泡；助手开放正文与单个头像；保持先前实现的渐进文本播放 |
| 输入区 | 文字、附件选择/粘贴、排队/steer、停止、发送 | 细边框与微弱阴影的输入容器；附件在草稿中显示；发送实心深色；交互状态保持真实 |
| 任务 | 读取 Host schedules、SSE 变更、打开关联会话 | 独立任务页：待执行/已完成两类，列表与详情；状态细节放在详情，不新增搜索 |
| 文件系统 | /root/harness 逐层展开、刷新、复制路径、分页 | 右侧约 320px 资源面板；小屏为侧滑覆盖层；不展示为本地文件库 |
| 插件市场 | 后端目录、安装/更新/启停、详情、授权、教程 | 同一浅色/深色体系；桌面两列、窄屏一列；官方图标和后端描述原样驱动 |
| 设置 | 模型、协议、搜索供应商、主动服务 | 同一壳层保留导航；小标题、表单分组与细边框，减少重按钮感 |
| 登录 | 创建/打开账号、语言 | 克制居中表单；Go Bot 标识；登录前也可切主题与语言 |

本次任务界面只新增查看、刷新、详情和打开关联会话；创建/修改任务仍可通过现有 Agent 工具和移动端完成。不改后端 schedule 的计算、存储、投递与归档机制。

## 3. 布局及自适应

- 大屏：左轨 64px；会话侧栏展开 264px；中央正文上限约 840px；文件面板 320px。会话侧栏默认收起，点击会话图标切换；在其它页面点击会话返回聊天并展开列表。
- 侧栏和右侧文件面板占用真实布局空间，中央区域可收缩；中等宽度的文件系统改为覆盖层，避免正文被压成窄条。
- 任务页内部为列表和详情两栏，窄屏切成列表/详情两步；不显示空的右侧推荐容器。
- 窄屏 Web 保留图标左轨；会话和文件系统使用有遮罩的侧滑面板。主内容、表格、模型菜单和设置表单不产生页面横向溢出。
- 切换设置、任务与插件不重新建立 Host SSE，不丢弃已加载会话缓存；当前进行中的问题和审批继续按会话记录。

## 5. 字体、图标与内容

- 英文/数字：通过 Fontsource 本地打包 Inter Variable Latin，避免运行时依赖 Google Fonts/CDN。
- 中文：PingFang SC、Microsoft YaHei UI、Noto Sans CJK SC 等系统无衬线回退，按中文阅读调整字距和行高。
- 正文 15–16px，行高约 1.8；导航/表单 13–14px；辅助标签 11–12px。标题遵循 28/23/19/16px 层级，避免原界面中大字号和大按钮抢占正文。
- Markdown 保留现有语法能力，单独处理标题间距、列表缩进、引用边线、表格表头/行线/横向滚动、代码字体/背景和链接颜色。不混淆 Markdown 图片文本与 image 内容块。
- UI 图标统一 Lucide，主要为 18–20px、1.6–1.75px 描边，无混杂填充图标。
- PDF、Word、Excel、PowerPoint、Markdown 文件图标复用项目已采用的 vscode-icons 免费资源，保留 MIT 许可。
- 图片为适度大小的正方形缩略图，多图横向排列并在容器内部滚动；点击以黑底全屏查看，可关闭和下载。文件卡呈现文件类型图标、名称、描述和明确下载动作，不制造 artifact 类型。

## 6. 动效和交互

- 窄导航切换整个工作区，默认选中会话；任务、插件市场和设置替换聊天视图，聊天状态仍保存在原有缓存中。会话列表只在会话入口展开。
- 空会话首次发送：居中 Logo 与引导文字淡出，同一个输入框平滑下移到底部，消息区淡入；不更换输入框节点，不丢失焦点，失败时保留草稿并恢复空会话布局。
- 空会话欢迎区采用更突出的 128px Logo、30px 标题和 20px 引导文字；窄屏适度缩放，低高度窗口压缩欢迎区占位，避免与顶部工具条或输入框相碰。

- 首次进入：壳层先稳定出现；当前页面内容 240–420ms 淡入/上移 8–12px；同组元素轻微错开，整个过程约 600ms 内完成。
- 会话侧栏：布局宽度随开关变化，内部内容向右进入，约 240ms，关闭更短；聊天缓存和输入草稿不因开关卸载。
- 页面切换：内容区短淡入，不重播整段会话消息；聊天滚动时不逐行做入场动画。
- 工具组：细线折叠行，状态清晰，展开时显示各工具，不把工具名做成大按钮；更新状态不导致整组重播。
- 主题切换：短颜色过渡，不闪白、不重载；系统减少动态效果时取消位移和动画。
- 模型/权限/账号菜单、弹窗：点击外部、Escape 可关闭，适当还原焦点；阻塞业务操作期间保留原有必要保护。
- 审批、提问立即交互，不能等待正文播放；停止和发送继续依据真实后端状态。
- 默认插件准备、安装进度和错误为轻量状态反馈，不能覆盖整个页面或阻止导航。

## 9. 实施与验收记录

- 壳层由 `layout/NavigationRail`、`WorkspaceHeader` 和 `Theme` 组织；样式拆为 shell、chat、settings、tasks，插件页面使用相同颜色变量。主题脚本在应用挂载前读取本地偏好，字体随构建自托管。
- 新增 Web 任务浏览器，使用原有 `/v1/host/schedules` 和 `schedule/changed` 通知。真实创建了周期、暂停、到期完成三类测试任务，验证分类、详情、时区、最近投递和关联会话；验收后移除了这些临时任务。
- 真实浏览器检查 1440×1000、1024×800、768×900 和 390×844。桌面左轨实测 64px、展开栏 264px，聊天区从 x=64 移至 x=328；检查的四档宽度没有文档横向溢出。窄屏会话栏和文件栏覆盖显示，主内容暂不可交互，关闭后恢复焦点。
- 中英切换、深浅切换及刷新后的本地偏好保持正常；浏览器确认 Inter 已加载。插件市场、详情、安装状态、启用、API Key 授权表单和取消授权均以真实 QA Host 验证，未填写真实服务密钥。临时安装的测试插件已移除。
- 使用模拟模型，经真实 Controller → Host → SSE 和 Go 工具执行链验证流式 Markdown、`shellexecute`、`readimage`、`present`、审批与提问。实际下载并读取交付文件；图片可黑底全屏打开和关闭；权限审批后继续，问题回答后继续。未进行新的真实模型付费调用。
- 模型/权限菜单外部点击收起；附件选择只进入草稿，切到设置再返回仍保留；归档确认可取消；主会话仍不可归档。会话缓存和单条 Host SSE 沿用现有机制。
- 首次发送录屏发现 Logo 的入场动画会覆盖退出透明度过渡，已修正并重录。实测透明度由 1 → 0.81 → 0.35 → 0.11 → 0，输入框纵坐标从约 584px 连续移动至 864px，焦点保持 `message`。录制为 `.local/web-redesign/first-send.gif`。
- 前端 39 项测试通过，TypeScript/Vite 生产构建通过，Linux arm64 Controller（嵌入新 Web）构建通过，移动端类型检查通过，`git diff --check` 通过。最终浏览器控制台未记录错误。本轮没有重新打移动端包或验证 ECI。
- 测试入口为本机 8084 QA Controller；8080 原服务未替换。模拟端点已删除，测试会话模型与默认端点已恢复，模拟模型服务已停止。截图、视频帧、临时脚本和日志均位于 Git 忽略的 `.local/web-redesign/`；原型原始媒体未加入仓库。
