## Reproduce locally

```bash

make race
./scripts/smoke-image.sh
python3 scripts/smoke-cli.py
RUN_DOCKER_INTEGRATION=1 \

```

For independent format verification, install the pinned upstream checkout's
workspace dependencies, then run from that checkout:

```bash
node --import tsx/esm /absolute/path/go-bot/scripts/verify-upstream.mjs \
  /absolute/path/upstream-checkout \
  /absolute/path/go-bot/.cache/validation/docker-container.v4.jsonl \
```

logs or production conversations. The Docker tests clean up their exact managed
containers.

## Account memory and history search

The native Agent test verifies same-turn memory updates, persistence through
compaction after the original tool result is replaced, and current-memory
loading on resume and fork. The Docker integration test checks the system
prompt received by a Responses fixture, confirms that memory survives Host
replacement, rebuilds the FTS5 index from the account volume, indexes a new
message appended to the resumed session, and checks
archive filtering and isolation between two account Hosts.

```bash
CGO_ENABLED=0 go test ./...
docker build -f build/Dockerfile.host -t go-bot/host:memory-check .
RUN_DOCKER_INTEGRATION=1 HARNESS_TEST_HOST_IMAGE=go-bot/host:memory-check \
  go test ./tests/integration -run '^TestDockerMemoryAndHistoryRebuild$' -count=1
```

Live ECI with NAS verification is deferred. The same replacement scenario can
run on ECI with NAS. From a runner that can
reach ECI's private Host endpoint and run the Redis fixture, use an ECI NAS
profile with the updated Host's Ready image cache. Use a fresh fixture account
with an empty NAS directory at `/go-bot/<account>`. The test starts a
Responses fixture on the runner, so its URL must be reachable by both ECI
instances. It creates and releases those two instances. The fixture account's
NAS files remain available for inspection.

```bash
HARNESS_TEST_ECI_PROFILE="$PWD/.env.eci" \
HARNESS_TEST_ECI_ACCOUNT=fixture-memory-smoke \
HARNESS_TEST_ECI_MODEL_URL=http://runner-private-address:9081 \
  go test ./tests/integration -run '^TestECINASMemoryAndHistoryRebuild$' -count=1 -timeout=20m
```

Set `HARNESS_TEST_ECI_FIXTURE_LISTEN` if the runner should listen on a different
address or port from the fixture URL.

### Official agent-browser installer

Both Host architectures build with the upstream npm package and Vercel Skills
CLI. The installed Skill matches the pinned upstream file byte for byte.
