# 会话图片与工具调用展示

状态：按确认的轻量版接入 Web 和移动端；查看图片使用紧凑尺寸。

## 展示规则

- `readimage` 中文显示为「查看图片」。连续调用合并为独立的图片工具组，默认展开，可收起；文字、其他工具或文件打断后另起一组。
- 图片工具组不再显示一套普通工具卡片和另一套重复图片。保留名称、张数、进行中或完成状态，以及展开入口。
- `generateimage` 保留相同图片展示能力，但本次不重新注册或启用该工具。
- 查看图片的预览为 118px 正方形，沿左侧正文边界排列；使用轻量标题，不加外层容器。
- 交付图片为 Web 164px、移动端 146px 的正方形预览，横向排列。圆角分别为 10px、11px；间距 10px。打开后完整展示原图比例。
- 横向溢出时，边缘由实到虚；滑动进入时渐显、离开时渐隐。只有存在溢出的边缘才遮罩，到达起点或终点时对应侧清晰。
- `present` 明确交付的 PNG/JPEG/WebP/GIF/AVIF/BMP 图片自动获取并预览；其他文件仍使用原有点击下载卡片。SVG 和 HTML 不自动作为图片预览。无法解码的交付图片退回文件卡片。
- 移动端保存图片进入本地图片区及手机图库，按现有保存流程请求图库权限；交付图片以账号与后端路径识别，不进入文件区。浏览图片本身不会将它存入本地库。

## 数据与职责

沿用现有 Host SSE、`tool/result.images`、公开 `assistant/message` 文件块和 HTTP 文件内容接口。查看图片来自附件系统，交付图片继续来自工作区路径，不复制到上传附件区，不解析 Markdown 链接或扫描工作区创建交付。

`groupDisplayBlocks` 为双端提供同一分组逻辑；仅将呈现视图转换为图片工具组或图片行，不改动会话日志事实、Agent 执行或交付机制。图片文件扩展名只决定是否尝试预览，实际无法显示时回退。

Web 使用 CSS alpha mask；移动端使用 Expo 支持的 MaskedView 与已有 LinearGradient，实现真正透明的边缘渐隐，保留页面原有底色。

## 验证范围

验证连续查看、文字和其他工具打断、异步返回顺序、交付图片与文档混排、收起再展开、横向滑动、边缘渐隐、全屏预览和移动端保存。通过可控模型协议响应驱动真实 Controller → Host 工具执行与 SSE，不调用付费模型。保留实际界面截图在本地忽略目录 `.local/media-integration-qa/`。
