# 同账号客户端与移动端设备分栏

## 范围与职责

在移动端「我的」现有定时任务、设置、插件市场分栏后加入设备分栏，保留现有 Muse 白色系、仅图标导航和滑动选中底片。参考 [Taste Skill](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md) 的统一间距、克制容器、清晰层级与无障碍原则；不套用其营销网站布局，不调整聊天消息表现。

当前接入 Web 与移动端。桌面客户端正在其他会话开发，本次不修改桌面项目；连接元信息协议允许 desktop 类型以便以后接入。Web 按用户要求只显示 Web，不收集或展示电脑型号。原生端按可获得的信息报告系统与设备型号，无法获取时显示 iPhone、iPad 或 Android，不推测具体硬件型号。

本功能展示应用客户端是否与 Controller 保持事件流，不代表机器是否开机。客户端类型与设备名称由客户端在现有 SSE 握手中报告；在线状态由 Controller 根据成功建立的连接维护。

## 客户端身份与连接

- 客户端持久化一个随机 clientId；Web 存浏览器 localStorage，移动端存应用 document 文件。它不是认证凭证，不使用硬件序列号或 MAC 地址。
- SSE 请求携带 X-Go-Bot-Client，值为 encodeURIComponent(JSON.stringify({id,type,platform?,model?}))。type 为 web、mobile 或 desktop；平台和型号可选且限长。Web 只报告 id 和 web 类型。
- Controller 只在上游成功返回 HTTP 200 text/event-stream 后登记设备，不因一次失败请求显示在线。元信息由 Controller 消费，不转发给 Host 或模型。
- 每条 SSE 都由 Controller 分配独立 connectionId，同一浏览器的多个标签页共用 clientId，但独立维护连接；关闭其中一个标签页不会把其他标签页判为离线。
- 连接期间每 30 秒续期一次，租期 90 秒；正常断开立即移除该连接，进程崩溃或网络静默失联最迟在租期后显示断开。重连沿用 clientId，恢复原设备条目。
- 不引入全局后台扫描、额外 WebSocket 或第二条 SSE。每条现有连接只负责自己的续期与收尾；状态采集失败不打断聊天。

## Redis 与 API

保持现有单账号 Hash user:<userid>，增加 clients 字段（JSON）；不增加 Controller 本地权威状态或新的 Redis 设备键。每个客户端保存 type、platform、model、lastSeenAt 和 connectionId → expiresAt 的连接租期表。时间均为 Unix 毫秒。

通过 Redis 事务更新该字段，避免两个客户端互相覆盖或影响模型、插件等字段。读取时计算 connected / disconnected，不依赖某台 Controller 的内存。清除过期租期，最多保留 50 台客户端，超过时淘汰最久未在线的已断开条目。

GET /v1/clients 使用现有 X-User-ID，返回当前账号的客户端列表。公开结果包含 id、type、platform、model、status 和 lastSeenAt，不暴露内部 connectionId 或租期表。接口不启动 Host，也不读取会话内容。

移动端设备分栏仅在可见且应用前台时每 5 秒刷新一次，也提供手动刷新；离开后停止刷新。正常断开在下一次读取时反映，静默失联按 90 秒租期判断，不承诺瞬时检测。每次重新进入立即读取当前状态。

## 表现

- 四个分栏使用现有单色 Lucide 图标；设备使用 MonitorSmartphone，选中与其他分栏一致，不显示导航文字。
- 内容顶部为「设备」和轻量刷新入口。当前设备可标注「此设备」，其他客户端按在线优先、最近在线时间排序。
- 设备页采用独立的轻薄列表设计：白色细边框分组容器、浅灰图标底片与组内分隔线，区别于定时任务卡片。统一左侧图标、设备名称、次级信息与右侧小圆点及状态文字；Web 的名称固定为 Web。留足纵向内边距，不叠加粗描边或大面积状态色。
- 连接状态用绿色小圆点＋「连接」，断开用红色小圆点＋「断开」；文字为 12 号，不使用胶囊徽章。英文对应 Connected / Disconnected，无障碍名称完整说明状态；断开项可显示最后在线时间。
- 加载、读取失败、只有此设备以及没有已报告设备等状态均有明确表现，失败保留已显示的数据并允许重试。
- 沿用系统字体、现有圆角和按压反馈，支持中文与英文，不改变头像与主导航布局。

## 验证

覆盖同账号多个设备、不同账号隔离、多个标签页、正常断线、旧连接结束与新连接并存、过期租期、Controller 重启后的租期恢复、元信息校验、上游握手失败，以及聊天数据不受影响。

检查 Web 和移动端的身份持久化、SSE 上报及移动端四分栏。使用真实 Controller / Redis 与多条 SSE 验证设备状态；移动端实际渲染并截图。视觉演示如使用可控数据会明确标注，不把演示设备冒充真实连接。


## 实施验证结果

- Controller 连接登记、握手失败、账号隔离、多标签页、正常断开与过期判断测试通过（含 race 检查）；真实 Docker Redis 验证只使用用户 Hash，生命周期及设置写入不覆盖设备字段。
- 前端 45 项测试、移动端 9 项测试、双端类型检查和 Web 构建通过。OpenAPI 已加入设备查询及 SSE 元信息说明。
- 使用实际 Controller / Host SSE 验证关闭单个标签连接仍保持在线、最后连接关闭后断开、重连复用条目。Android 模拟器完成中英文实际渲染与截图；截图中的 Web 条目来自测试用 SSE 客户端，并非浏览器截图。
- 最新 iOS Debug 包已安装并启动于已连接真机；实际账号上报 iOS 客户端，后端可读取连接状态。
- 本地 Controller / Host 已以最新源码重新编译并制作运行镜像，保留已验证的基础运行环境；运行中二进制 SHA-256 与本轮编译产物一致。插件远程化修改一并整合，默认两个插件通过 GitHub Release 重新安装并就绪。测试账号旧插件目录保留备份，账号、会话与凭证保留。
