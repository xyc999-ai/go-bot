# 移动端设计

当前界面以用户提供的 Muse 原图和 [Muse 官方设计说明](https://muse.ai/blog/how-we-designed-muse) 为主要参考，[Taste Skill](https://github.com/Leonxlnx/taste-skill) 辅助校准间距、字重和控件层级。完整规格见 [Muse 风格重设计方案](muse-redesign-plan.zh-CN.md)。

整体使用白色、浅灰与近黑线框图标，成功、警告、错误沿用克制的语义色。底部浮动导航只保留聊天、我的两个图标；我的页面使用定时任务、设置、插件市场三个图标分栏。导航和分栏不显示文字，但保留辅助功能名称和选中状态。用户默认头像使用项目 Logo，已设置的本地头像继续使用。

## 页面与数据

| 页面 | 交互 | 数据来源 |
| --- | --- | --- |
| 连接 | 输入 HTTP(S) 地址和账号，连接已有账号或创建账号；独立切换语言 | Controller 管理账号和 Host，手机保存连接配置；语言为设备偏好 |
| 聊天 | 抽屉切换或新建会话；组合菜单打开 Host 文件系统或插件市场；保留多行输入框、附件工具栏、模型和权限选择 | 会话历史与 Host 级 SSE 复用现有缓存、事件投影与消息播放机制 |
| 我的 / 定时任务 | 待执行、已完成两类，按日期分组；创建、查看、编辑、暂停、恢复、立即运行和跳转会话 | 当前账号 Host 的 Schedule，保持原规则和字段含义 |
| 我的 / 设置 | 模型、网页搜索、主动服务、语言、连接信息、退出登录、Stop Host | 模型和工具配置由 Controller 保存；头像按账号写入手机；语言不绑定账号 |
| 我的 / 插件市场 | 市场与已安装列表、详情、安装、启停、更新和授权；详情返回原列表位置 | 复用插件目录、安装状态与授权服务，不增加前端插件业务 |

## 呈现与交互

聊天顶栏覆盖在内容上方，以真实背景模糊和连续渐隐边界区分层次，滚动内容可以经过其后方；按钮和 Logo 保持清晰。顶栏头像独立展示，下方白色胶囊在 Go Bot 与“处理中 / Working”间平滑切换，尺寸固定；普通状态不附加提示。助手消息没有外层气泡，内部 Markdown、工具分组、图片、文件、内容顺序与生成动态保持原样。用户消息使用参考图中的浅蓝色气泡。输入框和“+”工具栏保留原有结构与交互。

我的页面头像与账号居中，分栏使用浅灰轨道和白色选中底片，随头像区域滚出后吸顶。底部导航采用近白底座、浅灰选中底片与近黑较粗图标。选中态不用蓝色，输入框聚焦不追加彩色描边或光圈。

外围菜单与底部弹层统一浅中性底色、细边和克制阴影；任务详情用浅灰底与白色信息卡区分层次。保持原有点外侧收起、脏表单确认、系统返回和外部授权返回规则。模型、权限、附件、提问和审批继续使用已有交互。插件安装不会阻止切换页面。

本地图片库、文件库与 Host 文件系统仍是不同入口。草稿选中的附件随发送提交，交付文件由用户下载后进入本地文件库；图片保存、分享和删除的语义不变。图标来源见 [图标清单](icons.md)。

页面切换和选中底片采用轻微位移、淡入与短缓出过渡，尊重系统减少动态效果设置；不改写助手执行过程的动画。
