# Go Bot 桌面端设计与实现

日期：2026-11-25。

## 产品与工程边界

独立 Electron + React + TypeScript + Vite 项目，存放在 `desktop/`，拥有自己的
package.json、锁文件、renderer、系统能力、测试和打包配置。初始界面从本仓库
Web 的实现迁入独立副本，随后分别维护；桌面端构建和运行不读取 `frontend/`。
不同时引入第二套组件库和视觉体系。后端协议继续使用 Controller HTTP/SSE。

首版连接已运行的 Controller，既支持本机回环地址，也支持可信网络的 HTTPS
地址。安装应用不自动安装 Redis/Docker，不改变 Agent 执行位置。文件面板仍然
展示 Host 文件；用户选择的电脑文件通过附件上传后才进入 Host。

## 网络、授权和系统能力

- 本地安全协议 `gobot://desktop` 加载打包页面和资源；聊天等 History 路径有
  明确的 SPA 回退，不使用 `file://`，也不加载远程网页作为应用代码。
- `/v1/` 由主进程代理到用户选择的单一 Controller 源。普通请求、multipart
  附件、二进制下载和 SSE 共用入口。SSE 转发 Response 流，不等待响应结束。
- 限定请求头，阻止 API 重定向跨源传送账号；保持请求取消语义。Controller
  来源请求头和 MCP authorize 的 origin 正文均采用所连接的服务源。
- OAuth 在系统浏览器完成，沿用后端 callback、state、PKCE 与状态事件；不把
  桌面内部协议作为第三方 OAuth 回调地址。
- sandbox、contextIsolation 开启，nodeIntegration 关闭，桥接仅提供配置、
  偏好、通知和应用命令。渲染进程不获得任意文件、shell 或任意网络接口。
- 外链仅允许 HTTP/HTTPS/mailto；禁止不受信任窗口、webview 和本地文件导航。
- 一个工作区保留一个 Host SSE；页面切换不断开，断网按游标恢复，休眠唤醒后
  重连，不重发用户消息和审批决定。
- 关闭窗口和退出应用均不停止 Host。macOS 默认隐藏窗口，Windows/Linux 默认
  退出；可选驻留托盘。应用完全退出后不承诺收到通知。
- 应用后台收到问题、审批或完成事件时显示不含正文的系统通知，点击定位会话。

## 2026-11-27：macOS 正式签名、公证与 DMG 发布

正式构建使用 Developer ID Application 证书及私钥，通过 App Store Connect
API 密钥认证公证服务。个人 API 密钥要求 Xcode 26 及以上，省略 Issuer ID。
签名从内部 Mach-O、框架和 Helper 应用向外进行；语言包、字体、图片和
`app.asar` 由资源封印保护，避免不必要的逐文件私钥调用。

`npm run release:mac -- arm64` 先构建、签名、验证 App 并运行原生及视频回归，
再用系统 `hdiutil` 生成包含 App、Applications 快捷方式及双语安装说明的 DMG。
只提交最终 DMG 公证一次；Apple 同时检查其内部 App。通过后为 DMG 附加票据，
为可写 App 取得同一提交签发的票据并生成 ZIP，核验 Gatekeeper、挂载内容及
复制安装后的行为，最终生成版本/架构独立的 DMG、ZIP、SHA256 和验证记录。

上传和等待处理分别输出进度，上传完成即记录提交 ID。处理默认等待 90 分钟，
拒绝、超时或其他验证失败均阻止正式产物生成；保留提交记录及可用日志。
`--from-app` 可复用版本、架构及签名匹配的已有 App，避免重新签名应用。

统一的客户端发布工作流 `client-release.yml` 仅由 `workflow_dispatch` 手动触发，
推送代码、PR 和版本标签均不自动启动客户端发布构建。在 Actions 选择 Client release，点击
Run workflow，选择构建分支并填写自定义 Tag；无需提前创建 Tag。正式发布工作流保持一次运行完成，使用独立 macOS arm64、Intel runner
和 Windows x64 runner，并行构建 Android ARM64 签名 APK（各客户端统一版本）；Windows 按用户要求不配置签名。版本从 `desktop/package.json` 读取并核对移动端和 Web 一致，Tag 不与版本绑定；
不存在的 Tag 在创建草稿 Release 时使用本次构建提交。Release 标题为 `Go Bot v<版本>`。全部产物验证后才创建/更新草稿
Release，不覆盖已发布版本。macOS 需要四个仓库 Secrets、团队/签名身份变量，
通过终端配置脚本隐藏输入 `.p12` 保护密码。Android 另需四个签名 Secrets 和
证书指纹变量，配置见移动端 README。证书私钥不写入源码或应用资源。

本机 macOS arm64 正式 DMG 已完成单次容器公证、票据和 Gatekeeper 验证，
原生聊天、菜单、侧栏、上传下载及视频测试通过。该轮上传约 66 秒，Apple
处理约 62 秒；这些实测耗时不构成后续提交的处理时间保证。桌面 70 项单元
测试、生产构建、工作流检查及最终安装包校验和验证通过。Intel、Windows
仍需要对应 CI runner 的实际验证；本机没有 Rosetta，未宣称已完成 Intel 验收。
